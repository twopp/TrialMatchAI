# 中文 Mac 可复现使用与发布文档设计

## 目标

让新的使用者从 GitHub 拉取 `feature/deepseek-api` 分支后，能够在 Apple Silicon Mac 上按照中文教程独立完成环境安装、模型准备、配置、临床试验库构建、患者匹配和报告查看，并理解哪些步骤使用本地模型、哪些数据会发送给 DeepSeek。

文档针对当前已经验证通过的技术组合：

- BGE-M3：本地 CPU 向量检索；
- UIE-Medical-Base：独立 Paddle 环境中的本地 CPU 医疗实体抽取；
- Qwen3-Reranker-0.6B：本地 Apple MPS 条件重排；
- DeepSeek API：在线入排资格评估；
- TrialMatchAI：试验预处理、患者导入、匹配以及 HTML/JSON 报告生成。

## 交付内容

### 中文教程

新增独立的中文 Mac 教程，并从项目 README 链接到该教程。教程采用从零开始的顺序，覆盖：

1. 系统和软件要求；
2. 克隆指定分支并安装 TrialMatchAI 主环境；
3. 下载 BGE-M3 和 Qwen3-Reranker-0.6B；
4. 创建隔离的 `.venv-uie`，安装经过验证的 Paddle 依赖并下载 UIE-Medical-Base；
5. 复制 Mac 示例配置并创建本地 `.env`；
6. 验证 PyTorch MPS、PaddleNLP、模型缓存和配置；
7. 导入或放置自己的试验 JSON；
8. 构建试验库并运行 FHIR 或文本患者匹配；
9. 找到并打开 JSON/HTML 结果；
10. 处理常见错误以及理解首次运行耗时。

每段命令会说明作用。涉及具体文件路径时使用仓库相对路径或可由使用者设置的示例变量，不写入当前电脑的绝对路径。

### 可公开的 Mac 示例配置

新增 `config.mac.example.json`，保存已经验证的后端组合和合理默认参数，但不包含：

- DeepSeek API Key；
- 当前用户的绝对路径；
- 患者或试验测试数据；
- Hugging Face 缓存快照的绝对路径；
- 本地运行结果目录中的实际数据。

使用者将示例复制为被 Git 忽略的 `config.mac.json`，再按本地数据目录调整路径。DeepSeek 密钥只通过 `.env` 中的 `DEEPSEEK_API_KEY` 提供。

### README 入口

README 保留现有英文快速开始方式，同时增加醒目的中文 Apple Silicon 入口，避免把平台专用的较长步骤塞入通用说明。

## 安全与隐私边界

- 不提交 `.env`、`config.mac.json`、模型缓存和生成结果。
- 不提交现有患者测试包或任何可识别患者的信息。
- 教程明确说明：BGE、UIE 和 Qwen 在本地运行；启用 DeepSeek 资格评估后，候选试验的标准和患者摘要会发送至配置的在线服务。
- 教程建议首次验证使用合成或去标识数据；处理真实患者数据前由使用者自行完成机构合规和数据授权检查。
- 示例配置只引用模型名称，不打包或分发模型权重。

## 验证方法

提交前执行以下检查：

1. JSON 解析示例配置，确认字段与当前配置模型兼容；
2. 搜索教程和示例配置，确认没有 API Key、当前用户名、真实患者编号或本机绝对路径；
3. 执行 Ruff 和完整 pytest 回归测试；
4. 检查 README 中的相对链接可解析；
5. 用当前已下载的模型对示例配置执行配置加载或预检；
6. 检查 Git 差异，只提交预期的代码与文档，不提交本地 `config.mac.json`。

完整模型端到端回归已经在当前 Mac 上验证过；本次文档工作以配置可加载和自动化测试为主要发布门槛，避免重复向 DeepSeek 发送患者数据。

## 发布方式

文档、示例配置以及必要的轻量验证改动提交到当前分支 `feature/deepseek-api`。确认本地测试通过后，将本地尚未发布的全部提交推送到 `origin/feature/deepseek-api`。不直接修改或合并远程默认分支。

## 完成标准

- 新使用者无需查看本次对话即可完成安装和首次运行；
- 所有必需模型、依赖版本、配置项和命令均有明确说明；
- 教程能够区分首次试验库构建与日常患者匹配；
- 常见报错包含可执行的排查建议；
- 仓库不包含密钥、真实患者数据或机器专用配置；
- 测试通过且本地分支成功推送到远程同名分支。
